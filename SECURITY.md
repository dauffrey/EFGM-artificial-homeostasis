# Security Policy

## Scope

This repository is for controlled research into artificial homeostasis and agent self-regulation. Experiments must remain confined to harmless toy or explicitly authorized environments.

## Prohibited content

Do not commit secrets, credentials, tokens, private datasets, production connection strings, privileged endpoints, or instructions intended to bypass real-world security boundaries.

## Reporting

If you identify a security weakness in this repository, do not demonstrate it against third-party systems. Report the issue through a GitHub issue only when disclosure is safe; otherwise contact the repository owner privately through an appropriate channel.

## Research boundary

Results concerning sandboxing, containment, self-regulation, or agent persistence are to be evaluated only in controlled environments owned by or explicitly authorized for the experiment.
