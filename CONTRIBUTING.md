# Contributing

This repository is a controlled experimental research environment.

## Contribution policy

Public visibility does not imply open write access or open experimental authority.

External contributors may open issues or pull requests for discussion, but no external change is considered part of the experimental record unless it is explicitly reviewed and accepted by the repository owner.

## Experimental integrity

The following must not be changed after preregistration for an active experiment unless the experiment is explicitly invalidated and restarted:

- hypotheses
- success or falsification criteria
- disturbance schedules designated as frozen
- thresholds and regulator parameters designated as frozen
- primary metrics
- comparison baselines
- random seeds designated as frozen

Results must not be removed or rewritten because they are unfavorable.

Any post-hoc modification must be identified as exploratory and must not be represented as preregistered evidence.

## Pull requests

Pull requests should explain why a change is needed, whether it affects an active experiment, and whether it changes any frozen experimental condition.

Unsolicited changes to active experimental code, data, results, or preregistration records will not be merged.

## Security

Do not include credentials, private data, production endpoints, or privileged infrastructure in experiments. This repository is intended for controlled, harmless research environments only.
